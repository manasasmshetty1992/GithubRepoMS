# OctoFit Tracker

OctoFit Tracker is a responsive fitness dashboard for students and gym teachers. Students can log activities, follow team goals, compare leaderboard rankings, and explore personalized workout ideas. Gym teachers can switch to a teacher profile to see a class-focused dashboard.

## Run locally

```bash
npm install
npm run dev
```

Activity logs and team membership are saved in the browser's local storage. The app uses sample data and does not require a backend.
